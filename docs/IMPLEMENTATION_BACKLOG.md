# خطة التنفيذ المرحلية — atsh-ai

هذه الوثيقة تحول المرجع إلى مهام تنفيذ قابلة للفحص. لا تعني أن المهام اكتملت لمجرد إدراجها.

## المرحلة 0 — قرارات وبنية أساسية
- [ ] تثبيت إطار الواجهة والخادم، وقاعدة البيانات، ومزود المصادقة، والاستضافة.
- [ ] إعداد بيئات التطوير والاختبار والإنتاج وإدارة الأسرار خارج Git.
- [ ] تحديد اللغة الافتراضية ودعم العربية RTL والإنجليزية LTR.
- [ ] إعداد فحوص التنسيق والأنواع والاختبارات والبناء في CI.
- [ ] إضافة سياسة أمان وخصوصية ونسخ احتياطي واستعادة.

## المرحلة 1 — الموقع العام
- [ ] هيكل متجاوب مع تنقل واضح.
- [ ] الرئيسية والخدمات والمنتجات والأعمال ومن نحن والتواصل.
- [ ] حالة حقيقية لكل منتج، وعدم عرض بيانات عملاء أو نتائج غير موثقة.
- [ ] نموذج تواصل مع تحقق خادمي وحالات نجاح وفشل واضحة.
- [ ] بيانات SEO الأساسية وسياسة الخصوصية المناسبة.

## المرحلة 2 — هوية الدخول ولوحة الإدارة
- [ ] مصادقة موثوقة وإدارة جلسات آمنة.
- [ ] تفويض خادمي واختبارات وصول غير مصرح.
- [ ] إدارة محتوى الصفحات والخدمات والمنتجات والمشروعات.
- [ ] إدارة طلبات التواصل وسجل التدقيق.
- [ ] مسودات ومعاينة ونشر وأرشفة.

## المرحلة 3 — مركز الدعم
- [ ] إنشاء تذكرة وتصنيفها وتحديد أولويتها ومسؤولها.
- [ ] حالات التذكرة وسجل الردود.
- [ ] فصل الملاحظات الداخلية عن ردود العميل.
- [ ] حماية المرفقات وتحديد معدل الطلبات.
- [ ] إشعارات موثوقة بعد إعداد مزود الإرسال.
- [ ] محادثة حية عبر مزود معتمد أو بديل صريح يحول الرسائل إلى تذاكر.

## المرحلة 4 — بوابة الموظفين والمهام
- [ ] حساب وملف شخصي لكل موظف.
- [ ] صلاحيات HR والمدير والموظف.
- [ ] مهام ومسؤوليات ومواعيد وحالات وتحديثات.
- [ ] إعلانات داخلية وطلبات مساعدة.
- [ ] تقارير محدودة حسب الدور.

## المرحلة 5 — الحضور والانصراف
- [ ] تسجيل دخول وخروج بختم وقت خادمي.
- [ ] معالجة التسجيل المكرر أو الحالات الاستثنائية.
- [ ] طلب تصحيح وموافقة وسجل تغييرات.
- [ ] قواعد الدوام والإجازات بعد اعتماد سياسة مكتوبة.
- [ ] تقارير للفترة والفريق مع صلاحيات مناسبة.

## المرحلة 6 — التحقق والإطلاق
- [ ] اختبارات الصلاحيات لكل دور ولكل سجل.
- [ ] اختبارات النماذج والمرفقات والرسائل المزعجة.
- [ ] اختبارات الهاتف وإمكانية الوصول والأداء.
- [ ] اختبار النسخ الاحتياطي والاستعادة.
- [ ] مراجعة الخصوصية والأمن والمتطلبات القانونية المنطبقة.
- [ ] نشر مرحلي واختبار حي وخطة تراجع.

## قاعدة العمل
لا نضع بيانات اعتماد أو مفاتيح في المستودع، ولا ننشر إلى نطاق حي قبل معرفة
الاستضافة وإعداداتها. كل مرحلة تُعتبر منجزة فقط بعد تنفيذها واختبارها والتحقق
من نتيجتها.
